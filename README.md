# Social Media App named App

This project is a simple social media app where users can create accounts, log in, make posts, send messages, and have a friends list.

# purpose

The purpose of App is to have the simplest social media app possible, everything viewable from one page, posts, messages, and friends list.

# users

The users will be people who want to quickly view friends posts and send messages easily.

# features

- Register for an account
- Log in to an account
- Edit and delete an account
- Create, view, edit, and delete posts
- View a friends list
- Send and receive messages
